# Shaolin Temple 3D Tour

A 3D walking tour of the Shaolin Temple (嵩山少林寺) in the browser, for friends who love Shaolin and have not yet been able to go. The aim is to make them want to visit.

Unofficial and not affiliated with the temple.

Status: planning. No application code yet.
